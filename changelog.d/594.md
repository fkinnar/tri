- **Added**: creation metadata (#277): sets of author, copyright, usage terms, caption, title, location (`[iptc.sets.<id>]`, `{year}` and `{name}` in the values) written as XMP, in the file for JPEG / TIFF / PNG / WebP / HEIF without recompression and in the sidecar for a RAW. A field already filled is kept unless the set lists it in `replace`. Put by an export preset (`metadata` key), on the selection ("Put the creation metadata…") or with `tri --iptc <set>`; shown in the metadata panel.
- **Added**: a "Metadata" list in the export dialog, set to the preset's (`metadata` key, formerly `iptc`): as they are, a set of creation metadata, or all removed ("strip": no camera, date or GPS, only the image with its colour profile and orientation, without recompression; JPEG, PNG and TIFF). In the settings, the default set and a preset's metadata are chosen from a list.
