- **Added**: creation metadata (#277): sets of author, copyright, usage terms, caption, title, location (`[iptc.sets.<id>]`, `{year}` and `{name}` in the values) written as XMP, in the file for JPEG / TIFF / PNG / WebP / HEIF without recompression and in the sidecar for a RAW. A field already filled is kept unless the set lists it in `replace`. Put by an export preset (`iptc` key), on the selection ("Put the creation metadata…") or with `tri --iptc <set>`; shown in the metadata panel.
