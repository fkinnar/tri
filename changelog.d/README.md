# Changelog fragments

One entry per pull request, in both languages: `<PR number>.md` (English) and
`<PR number>.fr.md` (French), each one or more `- ` list items written as in
`CHANGELOG.md` / `CHANGELOG.fr.md`. `scripts/changelog.py collect` moves them into the
changelogs when a version is prepared. See `doc/en/build.md` ("Changelog").

Fragments de l'historique : une entrée par pull request, dans les deux langues (`<n>.md`
en anglais, `<n>.fr.md` en français). Voir `doc/fr/build.md` (« Historique »).
