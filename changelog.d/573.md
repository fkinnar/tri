- **Find a moved folder**: in All photos, photos whose folder is gone are greyed, with the reason on hover: disk unplugged, or folder not found. "Find its folder" (`g l`, right-click) looks for it on the disks, the home folder and the favourites, and checks that it holds the same photos. If it is not found, a box asks where it is. The index, the cache and the sorting data then follow it.
- Camera cards (under a `DCIM` folder) are never added to the index.
- The folder opened at launch is now recorded in the index, and a folder moved or renamed in tri takes its index entries along.
